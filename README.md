## What it does

`main.py` writes a single line of text — one quiet, earned moment of
pride — to `/output/entry.txt`. The line is fixed and deterministic, so
every run produces the same bytes.

## The line

> The baker's apprentice pulled the first loaf she had shaped alone from
> the oven, tapped its crust, and heard it sing back.

## Run

```sh
python3 -P -s main.py
```
